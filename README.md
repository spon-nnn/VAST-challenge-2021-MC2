# VAST Challenge 2021 — Mini-Challenge 2

Interactive visualization dashboard for analyzing GASTech employee movement and transaction data to identify anomalous behaviors.

## Running locally

1. Navigate to the project directory.

2. Start a local HTTP server on any available port, e.g.:

   ```bash
   python -m http.server 8080
   ```

   Or using Node.js:

   ```bash
   npx serve . -p 8080
   ```

3. Open your browser and go to `http://localhost:8080`.

> Any port works — just avoid ports already in use on your machine.

## Requirements

- A modern browser (Chrome, Edge, or Firefox)
- Python 3 **or** Node.js (for the local server)
- No build step or package installation required
